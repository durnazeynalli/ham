# The Ham

A responsive creative agency landing page and portfolio website built with vanilla HTML, CSS, and JavaScript.

**Live Demo:** [https://durnazeynalli.github.io/ham/](https://durnazeynalli.github.io/ham/)

## Overview

"The Ham" is a multi-section agency website designed to present company services, capabilities, and a categorized project showcase. It organizes work samples into specific domains such as graphic design, web design, landing pages, and WordPress development.

## Features

- **Structured Landing Page:** Hero header section, informational sections, and portfolio showcases.
- **Categorized Work Gallery:** Organized project visual assets across multiple creative disciplines (Graphic Design, Web Design, Landing Pages, WordPress).
- **Vanilla Architecture:** Built without external libraries or build tools, providing fast load times and clean native browser execution.
- **Interactive Front-End:** Powered by custom JavaScript for client-side interactions and dynamic presentation.

## Tech Stack

- **HTML5:** Semantic document structuring
- **CSS3:** Custom layout styling, components, and media design
- **JavaScript (ES6):** Client-side scripting and UI behaviors

## Getting Started

Because this project is built entirely with standard web technologies, no build steps or package managers are required.

### Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/durnazeynalli/ham.git
   cd ham
   ```

2. **Open the project:**
   - Open `index.html` directly in any web browser, or
   - Serve it using a lightweight local development server (such as the VS Code Live Server extension, `python3 -m http.server`, or `npx serve .`).
